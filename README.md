# Offline Map tiles

Static map tiles for the [Offline Map](https://github.com/sorintanase100/garmin-offline-map-app)
Garmin Connect IQ watch app. The watch downloads tiles from here to extend its
packaged coverage, then renders them fully offline.

Tiles are plain files, so this needs no tile server, API key or renderer.

## Layout

```text
catalog.json                              every published region
<country>/<city>/index.json               that region's grid
<country>/<city>/<level>r<row>c<col>.png  the tiles
```

For example:

```text
https://sorintanase100.github.io/garmin-offline-map-tiles/catalog.json
https://sorintanase100.github.io/garmin-offline-map-tiles/romania/bucharest/index.json
https://sorintanase100.github.io/garmin-offline-map-tiles/romania/bucharest/dr005c006.png
```

Country and city are lowercase ASCII slugs, so a watch can build a URL by
plain concatenation with nothing to escape.

## Regions

| Region | Tiles |
| --- | ---: |
| Romania / Bucharest | 274 |

Adding a region means adding a folder and a catalog entry. Paths, names and
schemas already published do not change, because watches store them.

## Tile format

- Levels: `d` at 2.5 m/pixel, `o` at 10 m/pixel
- 390 × 390 px, 16 colours, PNG
- Names are fixed width, so the folder sorts in grid order

Generated by `tools/publish_tiles.py` in the app repository.
